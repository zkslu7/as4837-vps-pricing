## 买AS4837 VPS之前，这几个参数比线路名字更重要

**带宽上限和月流量是否匹配实际用途。** 如果只是搭建一个小站或者做远程办公跳板，50-100Mbps、几百GB流量完全够用；如果涉及视频转发、批量下载或者对外提供服务，1Gbps大带宽加大流量套餐才有意义，否则多花的钱等于浪费。

**机房位置和虚拟化架构。** 洛杉矶是目前AS4837产品最常见的落地机房，因为这里到中国大陆的国际出口资源相对丰富。KVM架构相比容器虚拟化（如OpenVZ）在资源独立性和系统兼容性上更有保障，尤其是需要装Windows系统的场景，KVM基本是硬性要求。

**支付方式和退款政策。** 对国内用户来说，支付宝、微信支付比信用卡更省心。退款政策则直接关系到"踩雷成本"——如果48小时内不满意可以无条件退款，试错代价就小很多。
